## 🧭 Overview

**Stream.in** merupakan aplikasi **manajemen langganan terintegrasi** yang dirancang untuk membantu pengguna mengelola dan berlangganan berbagai **layanan hiburan digital** (seperti Netflix, Disney+, Viu, WeTV, dan lainnya) dalam satu platform.

Aplikasi ini menawarkan pengalaman berlangganan yang **fleksibel**, **aman**, dan **nyaman** — dengan sistem pembayaran yang beragam, manajemen akun otomatis, serta dukungan pelanggan yang responsif.

### 🎯 Tujuan
Dengan adanya Stream.in, pengguna tidak perlu lagi berpindah-pindah platform untuk mengatur langganan mereka.  
Melalui aplikasi ini, pengguna dapat:
- Memilih layanan streaming favorit mereka  
- Mengatur durasi langganan (harian, mingguan, bulanan, tahunan)  
- Melakukan pembayaran dengan mudah dan aman  
- Mendapatkan jaminan keamanan akun  
- Mengakses layanan pelanggan secara cepat

## 🚀 Fitur Utama

| Kategori | Deskripsi |
|-----------|------------|
| 🧑‍💻 **Authentication & User Management** | Registrasi, login manual, atau login via Google/Apple/Facebook |
| 💳 **Subscription Management** | Pilih paket layanan (harian–tahunan), pantau masa aktif, dan perpanjangan otomatis |
| 🪙 **Payment Processing** | Pembayaran mudah melalui bank, e-wallet, QRIS, atau voucher |
| 🔐 **Account Management** | Akses akun streaming (email & password) dengan garansi keamanan |
| 💬 **Customer Support** | Chat langsung dengan CS untuk melaporkan kendala |
| 🔔 **Notification System** | Peringatan masa aktif, status pembayaran, dan update akun |
| 📊 **Dashboard Overview** | Riwayat transaksi & status akun aktif pengguna |
